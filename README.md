# Klasifikasi Hotel Booking Demand
Tugas Praktikum Machine Learning - Universitas Pamulang

Repositori ini berisi implementasi model *Machine Learning* menggunakan algoritma **Decision Tree** untuk memprediksi pembatalan pemesanan hotel (*Hotel Booking Demand*).

## Alur Proyek
1. **Data Loading & Cleaning**: Memuat dataset dan menangani nilai kosong.
2. **Data Preprocessing**: Mengubah data kategorikal menjadi numerik menggunakan *Label Encoding*.
3. **Modeling**: Melatih model klasifikasi dengan algoritma *Decision Tree*.
4. **Evaluation**: Menguji akurasi model.
